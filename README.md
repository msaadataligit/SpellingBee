# 🐝 Bee Ready

A friendly spelling bee practice app. It runs entirely in the browser, with no accounts and no server.

- **Add a word list**: PDF, Word (.docx), Excel, CSV or text. Meanings, origins, example sentences and tips are picked up automatically.
- **Practice**: the app says each word in a British or American accent, in order or shuffled. Type the spelling, with an optional countdown timer.
- **Ask the judge**: definition, sentence, origin and part of speech.
- **Mistakes list and Retest**: each word stays on the list until it's spelled right twice in a row. Every past wrong spelling is kept.
- **Word info**: meaning, origin and memory tips. Missing details are looked up on Free Dictionary and Wiktionary, and the source is shown.
- **Progress**: day streaks, best run and trickiest words.
- **Privacy**: everything is saved in the browser on each device. Only a word itself is sent online, and only when looking up missing information. Use Settings → Backup to move progress between devices.
- **Works offline** after the first visit.

The word list file is not part of this repository. It is added in the app on each device.
